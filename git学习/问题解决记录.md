# 1.无法推连接远程仓库
错误提示：
```fatal : unable to access 'https://github.com/DummyStrophael/git_bash_wang'
failed to connectn to github.com port 443 after 21069 ms : Couldn't connect to server
```
原因：国内的连接重置或者DNS污染
解决：切换7897端口
```
 git config --global https.proxy http://127.0.0.1:7897
 git config --global http.proxy http://127.0.0.1:7897
 ```
# 2.无法push
错误提示：
```
To https://github.com/DummyStrophael/git_bash_wang.git
 ! [rejected]        master -> master (fetch first)
error: failed to push some refs to 'https://github.com/DummyStrophael/git_bash_wang.git'
hint: Updates were rejected because the remote contains work that you do not
hint: have locally. This is usually caused by another repository pushing to
hint: the same ref. If you want to integrate the remote changes, use
hint: 'git pull' before pushing again.
hint: See the 'Note about fast-forwards' in 'git push --help' for details.
```
原因：更新被拒绝，远程仓库包含本地没有的提交
解决：
```
git add .
git commit -m "修改"
git pull origin master --no-rebase
git push origin master
```

# 4.无法合并
错误提示：
```
git pull origin master --no-rebase
From https://github.com/DummyStrophael/git_bash_wang
    * branch            master     -> FETCH_HEAD
error: Your local changes to the following files would be overwritten by merge:
  holle.md
Merge with strategy ort failed.
```
原因：执行顺序反了(先push后add .)
解决：
```
git add .

git pull origin master --no-rebase
git push origin master
```
